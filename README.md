# Invoru

Instaladores de **Invoru** para Windows: registro mensual de videos por cliente y emisión de invoices.

## Instalar

1. Abrí la [última versión](https://github.com/EloyRolda/InvoTracker-releases/releases/latest).
2. En *Assets*, descargá `Invoru-Setup-x.y.z.exe` y ejecutalo.
3. El instalador no está firmado, así que Windows SmartScreen puede avisar: "Más información" → "Ejecutar de todas formas".

Se instala una sola vez por PC.

## Actualizaciones

La app busca versiones nuevas al abrirse, las descarga mientras trabajás y se actualiza al reiniciarla. No hace falta volver a esta página.

## Tus datos

Todo queda en tu PC, en `Documentos\InvoruData`. Desde Ajustes → Backups se puede guardar además una copia en una carpeta de Google Drive para escritorio.

Este repositorio solo tiene los instaladores; el código es privado.
